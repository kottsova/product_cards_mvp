## Изменение

- Кандидат Sulpak для `P12ED.NSAR + P12ED.USAR` теперь находится и по нормализованному коду без пробелов. Совпадение двух блоков определяется только по видимому содержимому страницы, с границами полного артикула и допустимыми пробелами вокруг `+`. Коды в URL сами по себе не подтверждают комплект.
- Сохранённая блокировка `www.sulpak.kz` дала `policy_host_stopped`; транспорт с запретом сети не сделал ни одного вызова. Поэтому содержимое страницы, её характеристики, фото и ссылка на инструкцию **не проверены**. В карточке сохранён точный URL кандидата и причина.
- Для цвета LG, включая цвет корпуса и цветовую отделку двери, итоговое значение не выбирается по одной базовой модели. Полный артикул с суффиксом после точки ищется первым по наблюдаемым маршрутам; короткая модель остаётся только кандидатом. Подтверждённый полный код на DNS может дать цвет варианта, если точная официальная страница его не дала. Цвет точной официальной страницы имеет приоритет; спор точных источников отправляется на проверку. Расхождение с базовой страницей остаётся в причине.
- В карточке и листе Excel `Готовность LG` явно видны блокировка Sulpak и неподтверждённый цвет полного артикула.
