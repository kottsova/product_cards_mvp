## 0. Поправка к этапу 24 (прежние отчёты не менялись)
Этап 24 утверждал, что панель характеристик отрисовывается на клиенте (0 строк на всех страницах) и что у телевизора одно фото. **Это было неверно.** На страницах товара характеристики лежат в статическом HTML: серверный аккордеон `pdd32-product-spec` (группа → пункты «название — значение»): телевизор 117 пунктов в 16 группах, пылесос 28/10, стиральная машина 85/10, Galaxy A37 64/15, микроволновая печь 59/10 (этап 8.5 писал, что значений рядом с подписями нет, — тоже неверно). Общий экстрактор искал `dl/dt/dd` и потому давал 0; галерея лежит в окне просмотра `hdd02-gallery__popup-vertical-image` (телевизор 8 фото, пылесос 15, стиральная машина 11), а я считал только картинки с кодом в имени и без учёта окна. Верно из этапа 24: на странице семейства смартфона (S25 Ultra) таблицы и sku нет; фото телефона не в странице товара, а на странице покупки.

## 1. Адаптер `product_tool/adapters/samsung.py` (без запросов, не подключён к worker)
Автоматически, по странице официального сайта:
- **Точный вариант** — только по содержимому: JSON-LD sku/name или заголовок (сильные признаки); код только в тексте страницы помечается слабым (`text_only`); адрес не считается. Различие региональных кодов остаётся открытым: у A37 каталог `SM-A376E`**`ZA`**`G`**`INS`**, страница `SM-A376E`**`DG`**`G`**`SKZ`** → только базовая модель, открыты регион и цвет, память (G) совпадает.
- **Таблица характеристик** — все пункты аккордеона по группам (682 пунктов на 11 страницах); пункт без названия несёт значение своей группы; пустые значения не создаются, ничего не додумывается.
- **Фото** — один актив один раз (размеры `$Q90_1368…$`/`$Q90_2052…$` — один актив, берётся самый большой), миниатюры (`-thumb-`, `104_104`) и 3D-модели (`.glb`, `.usdz`) в фото не входят; число миниатюр равно числу фото, то есть галерея полная.
- **Ссылки на инструкции** — ссылки страницы `CDCttType=UM`, с моделью, которую заявляет ссылка (`ModelName`); язык в имени файла — только подсказка порядка запросов.
- **Инструкция — три отдельных факта**: русский язык подтверждён текстом; файл связан с товаром официальной страницей (`exact_page` — страница показывает полный артикул, `base_model_page` — только базовую модель); точная модель названа внутри документа (модель каталога — отдельно от модели, заявленной ссылкой страницы; маски семейств, включая позиционные `WD1*T******`). Равенство кодов SC=VC (или LS=S) не вводилось: каждое имя сверяется с текстом отдельно. Файл без извлекаемого текста — ручная проверка, не вердикт.
- **Поиск страницы**: карта сайта по подстроке артикула; для смартфонов и планшетов — только ссылки-страницы хабов (адреса картинок, как ошибочно случилось на этапе 24, исключены; соседняя модель — не совпадение).
- **Дилерский фолбэк** (`merge_dealer_fields`): значение дилера добавляется только в поле, которого нет на официальной странице, только при точном совпадении модели и варианта, с отдельным источником на поле; официальное значение никогда не заменяется, расхождение записывается, а не используется. DNS знает только заранее проверенные адреса; для Samsung их нет, поэтому запросов 0, а готовый запрос дилеру формируется для карточек с пробелами.
