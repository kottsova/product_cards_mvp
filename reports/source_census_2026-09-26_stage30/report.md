## Формулировки пробелов по инструкции

| Пробел | Когда | Текст |
|---|---|---|
| `instruction_language_not_russian` | ни один прочитанный файл не содержит русского раздела | «все прочитанные файлы по тексту не русские, русского раздела в них нет» |
| `instruction_full_russian_manual_missing` (блокирующий) | сохранена только краткая памятка с русским разделом | «полной русской инструкции нет: сохранена только краткая памятка, в которой есть русский раздел; она полным руководством не считается» |
| `instruction_brief_guide_russian_section` (справочный) | то же | «сохранена краткая памятка (краткое руководство) с русским разделом; она не закрывает пробел по полной русской инструкции» + «краткая памятка (краткое руководство), русский раздел на стр. 8; модель в тексте не названа; полной русской инструкцией не считается» |

«Есть русский раздел краткой памятки» нигде не превращается ни в «все документы не русские», ни в «полная русская инструкция найдена». Русский раздел признаётся только при объёме русского текста, достаточном для «язык присутствует», и словах инструкции в нём; короткое русское юридическое уведомление в английском руководстве краткой памяткой не считается (тест).

## Как устроены правила (коротко)

- **Краткая памятка**: `samsung.russian_section()`, `is_brief_guide()`; документ сохраняется с языком «Многоязычная памятка (есть русский раздел)», заголовок «Краткая памятка Samsung · … стр. 8 …». Принятие: основание `brief_guide_russian_section`, `accepted=False`.
- **Вариант по данным товара**: `samsung.product_data_codes()` читает `modelCode`, `apiChangeModelCode`, `shopSKU`, `apiChangeShopSKU`, `originShopSku`, `data-model-code`, `data-shop-sku` (шаблонные `{{…}}` не считаются). Подтверждение только когда набор значений ровно `{код каталога}` и JSON-LD sku не противоречит; признак `product_data_code`, сила «сильная». Второй код в этих полях или другой sku отменяют подтверждение (тест на вставленном втором коде).
- **Запрос дилера**: `samsung_pipeline.dealer_missing_fields()` — характеристики и фото как прежде; «полная русская инструкция» считается недостающей, пока `samsung_readiness.full_russian_instruction_confirmed()` не вернёт истину (русский по тексту и принят по правилам). Для остальных брендов остался прежний `_compute_missing_fields`.
- **Закреплённый файл** `product_tool/worker.py`: одна строка (выбор функции для Samsung); запись миграции добавлена в `tests/_pipeline_migration.py`, хеш перепинирован. Остальные закреплённые файлы не менялись.
