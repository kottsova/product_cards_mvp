## Модель статуса и provenance

Русская инструкция в карточке и Excel имеет три состояния: `Проверена`, `Проверена, не найдена`, `Не проверена`. Второе состояние записывается только после проверки точного официального списка инструкций без русского документа. Сохранённый проверенный PDF имеет приоритет над старым отрицательным аудитом; смена артикула делает старый аудит неприменимым.

В Excel для документа P12ED указан тип источника `LG`; для MS2082F строка без PDF содержит статус отсутствия, URL официального support и тип `LG`. Характеристики и фото по-прежнему несут отдельные source keys; Sulpak не отождествляется с LG. Readiness thresholds не менялись.

Подробные структурированные свидетельства: [Sulpak](sulpak_verification.json), [поиск инструкции](ms_manual_search.json), [ответы региональных страниц](regional_support_checks.json), [проверка карточки/Excel/БД](live_validation.json).
