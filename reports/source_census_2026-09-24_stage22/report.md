## 4. Оценка на 578 строк и что остаётся
Правило: по сохранённым картам сайта каждая строка попадает в один из трёх классов: точный слаг (страница самого артикула), только слаг базового кода, ничего. На 24 строках класс совпал с фактическим уровнем совпадения страницы в **24 из 24** случаев. Выборка расслоена, а не случайна, поэтому доли ниже — оценки с широкими границами.

| Класс | Строк из 578 |
|---|---|
| Точный слаг (ожидается full_sku) | 434 (обе площадки 328, только RU 37, только KZ 69) |
| Только базовый код (ожидается base_model → `needs_review`) | 80 |
| Нигде | 64 (рыночный суффикс `_XX`: 36; действительно нет: 28) |

Оценки по пилоту: `done` — строки с одной точной страницей (0 конфликтов из 6) плюс строки с двумя (конфликт в 5 из 11, доверительный интервал 21–72 %); русская инструкция с названной моделью у 13 из 20 строк со страницей RU (65 %, интервал 43–82 %) — для 435 строк со страницей RU это ≈ 283 (с инструкциями, где модель не названа, — до 370).

**Пробелы, которые останутся, и что они требуют:**
1. **Рыночный суффикс `_KZ`/`_SU`** (36 строк, 35 найдены бы после его отбрасывания). Поиск сейчас их не находит (`DC90V9V9W.ABWPCOM_KZ` в пилоте — честный промах). Я не считаю суффикс частью модели LG без вашего решения: отбросив его, страница даст лишь `base_model`.
2. **80 строк только с базовой моделью.** В пилоте у 4 из 4 таких строк со страницей RU ссылка поддержки на самой странице (`/ru/support/product/lg-<код>`) печатает **полный артикул строки** (24MR400-B.ARUQ, 27MD5KL-B.AEU, VC5316NNTS.APSQCIS, RNC5.DRUSLLK). Это подтверждение варианта на самой странице, но не видимым текстом; правило D4 я не менял без вашего решения.
3. **Расхождения KZ и RU** на строках с двумя точными страницами (≈ 45 % в пилоте): значения различаются по существу (цвет, глубина), автоматически я их не решаю. Нужно правило: чьё значение выбирать (например, площадка целевого рынка).
4. **Инструкции.** (а) русская инструкция без названия модели в тексте — 4 из 20: принять ли связь «через страницу поддержки товара» как достаточную; (б) крупнее 25 МБ или только архив — 2 из 20; (в) на казахском вместо русского — 1 из 20; (г) строки без страницы RU (нет в карте RU): маршрут инструкций через KZ не исследован.
5. **Объём.** Один файл инструкции — в среднем около 11 МБ; на ≈ 435 строк со страницей RU это порядка 4.6 ГБ загрузки и ≈ 3.3 ч по времени пилота (20.6 с на строку, последовательно). Две строки из 24 подошли к пределу 60 с на задание.
6. Дилерская сверка (`dealer_cross_check_missing`) — рекомендательный пробел, не блокирует.
