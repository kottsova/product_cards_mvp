# Stage 44 — официальный кандидат поддержки LG для комплекта P12ED

Партия: `ae3d2cb381744ba8a811e54231233254` (`тест.xlsx`), строка товара `id=4`. Исходный Excel не загружался повторно. Исторические отчёты не изменялись.

## Причина пропуска

Рабочий поиск LG сначала сопоставляет артикул с URL товарной страницы в KZ/RU sitemap. Для комплекта он уже перебирал `P12ED.NSAR` и `P12ED.USAR` по отдельности в RU-поиске, но найденные RU-страницы показывали другие коды `P12EP...`. KZ-браузерный поиск остановлен подтверждённой проверкой браузера. Отдельная официальная KZ-страница **поддержки** из известной ссылки не входила в этот маршрут; документы проверялись только через ссылку поддержки с RU-товарной страницы. Поэтому «источники не найдены» было чрезмерным выводом.

## Проверка официального адреса

Заранее объявленный лимит: 6 новых HTTP-запросов, только `www.lg.com` и при найденном PDF `gscs-b2c.lge.com`; прекращение при 401/403/429 или подтверждённой странице проверки. Использовано ровно 6 запросов к `www.lg.com`, к Sulpak и PDF-хосту — 0. Ответы сохранены в `official_support/index.jsonl` и файлах рядом.

`https://www.lg.com/kz/support/product-support/cs-P12ED.USAR/` вернула HTTP 200. В её исходном HTML код `P12ED.USAR` есть в title/meta/canonical и маршруте приложения. **Товарная часть страницы в этом ответе пуста:** код `P12ED.NSAR` не напечатан, список руководств и прямые PDF-ссылки не отданы. Два наблюдаемых служебных адреса LG проверены тремя обращениями; ответы сообщили об обязательных параметрах и ошибке proxy. Пригодный ответ с товаром и документами не получен. Поэтому ни заголовок страницы, ни заявленная метка `Russian` не повышены до доказательства комплекта или проверенного русского PDF. Лимит остановлен, новые маршруты не подбирались.

## Изменения

- `product_tool/adapters/lg.py`: составные артикулы с `+`, `/`, пробелом или `&` разделяются на два кода только при явных полных артикулах с общей базой; один артикул со слешем остаётся целым.
- `product_tool/adapters/lg_support.py`: отдельная обработка наблюдаемых официальных support URL; универсальная проверка кодов из полей товара и ссылок регистрации. Один код комплекта даёт `component_only`; полный комплект подтверждается только двумя явными кодами. URL, title и meta остаются кандидатами. Характеристики и фото из support shell не переносятся. Прямой русский PDF проверяется существующим парсером по модели и русскому тексту только после подтверждения комплекта. В текущем сохранённом ответе PDF-ссылки нет, поэтому этот путь проверен только офлайн-фикстурой.
- `product_tool/worker.py`: support-кандидат и условная проверка документа включены в обычный путь LG. Сообщение задания теперь говорит о найденной официальной странице-кандидате и непроверенном комплекте. Порог `full_sku` не ослаблен.
- `tests/test_stage44_lg_support.py`: сохранённый KZ-ответ, разделители комплекта, региональный домен, один блок, регистрация второго блока, похожая модель, руководство с базовым кодом без двух артикулов, повторное сохранение без дубля.
- `tests/_pipeline_migration.py`: закреплены новые SHA-256 защищённых `lg.py`, `worker.py` и рабочей базы. До изменения базы создан `batches_before_support.sqlite3`; `apply_observed_support.py` применяет сохранённый ответ без сети. `replay_existing_batch.py` проверяет очередь, `run_once()` и Excel на копии базы.

## Целостность и итог

После изменения: `PRAGMA integrity_check = ok`, `foreign_key_check = []`. По сравнению с резервной копией: товаров 15→15, заданий 34→34, источников +1 только у product id=4, снимков источника +1, попыток чтения +1, событие задания +1; характеристики, фото и документы по числу не изменились. У остальных товаров страницы источников не изменились. Экспорт до/после: строка с `cs-P12ED.USAR/` на листе «Источники» 0→1. Защищённые файлы закреплены новой миграцией.

**Вердикт: `LG adapter not ready`.** Блокер именно в недоступных через проверенный статический маршрут данных KZ support: не удалось получить явную связь второго блока, прямой PDF и проверить его русское содержимое. Следовательно, критерии PASS для P12ED не выполнены и повторять остальные 11 строк сейчас не следует. Нужен новый наблюдаемый официальный ответ с товарными полями и ссылкой на PDF, после чего можно проверить документ штатным PDF-парсером и отдельно оценить характеристики/фото комплекта.

Дополнительное ограничение: автоматический поиск страниц поддержки на других рынках LG пока не реализован. В этом этапе использован только уже наблюдаемый KZ URL; адреса других стран не строились по шаблону и не запрашивались. Это также мешает признать LG готовым к более широкому прогону.
