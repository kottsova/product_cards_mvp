## Что показали сохранённые страницы

В 12 строках партии найдено 1 282 строки характеристик со значением: 357 отдельных `●`, 68 отдельных `O` (маркер RU таблиц), 13 отдельных `-` и 99 составных значений, начинающихся с маркера. Это 537/1 282 строк (42%). Из них 425 отдельных маркеров наличия объясняют заметную часть большого числа извлечённых атрибутов: это реальные строки технических таблиц, а не дубли. Маркеры `•`, `○`, `—` и пустые value cells в сохранённой выборке не встретились; поведение для них проверено синтетическими офлайн-тестами.

Исходная нормализация считала любое значение, **начинающееся** с `●` или `•`, простым `true`. В шести затронутых строках 85 из 99 составных значений так теряли остаток. После исправления только два значения вида «маркер + явная версия» дают `true` для наличия, а версия сохраняется отдельным фактом; 51 упорядоченный набор маркеров сохраняется как `bool_vector` (например `● / —` → `true/false`). Прочие составные значения остаются текстом для проверки, их нельзя приравнивать к `true`.

Из 22 конфликтов исходного Stage 48 четыре включали маркерное значение: три были ложными сопоставлениями (VK89309H, RNC9, ON66), одно у W4W8LVPKZHM остаётся реальным расхождением KZ/RU по подсветке сушильного барабана. Маркеры оказались существенной причиной **объёма** фактов, но не главной причиной всех ложных конфликтов. Секционный контекст и разные canonical concepts по-прежнему важны.

## Правило нормализации

| Сырое значение именно в value cell характеристики LG | Нормализованное значение |
|---|---|
| `●`, `•`, `O` | `true / bool` |
| `-`, `—`, `–`, `−` | `false / bool` |
| пустое | `unknown`; не является «нет» |
| `○` | `unknown`: в сохранённых страницах нет легенды, доказывающей смысл кружка |
| несколько маркеров через `/` | упорядоченный `bool_vector`, без потери позиции |
| маркер + явная версия | наличие и отдельный `<concept>_version` |

У значения без подтверждённого контекста value cell символ `-` не превращается автоматически в отсутствие. Каждый факт хранит исходные `raw_name`, `raw_value`, `section` и признак `value_cell` перед canonical mapping. `unknown` остаётся в исходных фактах и не входит в сравнение источников. Наличие Bluetooth и версия Bluetooth хранятся как разные понятия. Правила не завязаны на артикулы.
