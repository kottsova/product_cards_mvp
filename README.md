# Product Cards MVP

Локальный инструмент для загрузки Excel и первого сквозного поиска товара LG. Подтверждённые партии хранятся в SQLite, а поиск выполняет отдельный worker. Другие бренды, n8n и Google Sheets не подключены.

## Установка в Windows PowerShell

Откройте терминал в корне клонированного проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\product_tool\requirements.txt
```

## Запуск сайта и worker

В первом терминале, из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m uvicorn product_tool.web:create_app --factory --host 127.0.0.1 --port 8765
```

Во втором терминале, тоже из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m product_tool.worker
```

Откройте **http://localhost:8765/**. Оба процесса можно остановить клавишами `Ctrl+C`. Для одного локального запуска нужен один worker. Сайт и worker по умолчанию используют одну базу `data/batches.sqlite3`. Если задана переменная `PRODUCT_CARDS_DATA_DIR`, задайте одинаковое значение в обоих терминалах.

## Что попробовать

1. Загрузите `.xlsx` размером до 10 МБ. Проверьте предложенные лист и номера колонок; при необходимости исправьте их и нажмите «Обновить предпросмотр».
2. Исправьте бренд, основной артикул, запасную модель или категорию в таблице. Для подтверждения каждой строки нужны бренд и основной артикул.
3. Подтвердите партию и откройте товар LG из списка категории.
4. Выберите этапы: **1 — ссылка, 2 — описание, 3 — характеристики, 4 — фото**. Можно выбрать только нужные. Для этапов 2–4 worker сначала найдёт точную ссылку, если её ещё нет.
5. После постановки в очередь страница показывает текущий этап, сообщения и итоговый статус. Во время работы она обновляется каждые 5 секунд. Результат и ссылки на официальный источник остаются после перезапуска.

Публичный URL LG иногда содержит только базовую модель. Для артикула с региональным суффиксом адаптер дополнительно сверяет полный SKU внутри официальной карточки. Если точность не доказана, статус будет «Нужна проверка» и данные с кандидата не извлекаются. Недоступность сайта показывается как ошибка; пустой ответ не считается успехом.

## Данные и безопасность

Загруженные книги находятся в `data/uploads/`, база — в `data/batches.sqlite3`. Эти файлы, Excel, локальные настройки и секреты исключены из Git. LG-адаптер не использует старую папку, Google Sheets, фиксированный ID таблицы или `credentials.json`. Исходный парсер остаётся нетронутым.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты создают временные Excel и SQLite и не обращаются к интернету. Для обработки одного уже поставленного задания и выхода из worker:

```powershell
.\.venv\Scripts\python.exe -m product_tool.worker --once
```

## Состав проекта

- `product_tool/importer.py` — чтение Excel; [параметры импортёра](product_tool/README.md).
- `product_tool/web.py` — загрузка, подтверждение, страница товара и постановка задания.
- `product_tool/jobs.py` — очередь, прогресс и результаты в SQLite.
- `product_tool/worker.py` — отдельная обработка задания.
- `product_tool/adapters/lg.py` — поиск и извлечение с официального LG Казахстан.
- `docs/` — архитектура и рабочие сценарии.
