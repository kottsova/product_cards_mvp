# Product Cards MVP

Локальный инструмент для загрузки товаров из Excel. Сейчас он показывает предпросмотр, позволяет подтвердить колонки и исправить товары, а затем сохраняет партию по категориям. Поиск на сайтах, парсер и n8n пока не запускаются.

## Запуск в Windows PowerShell

Откройте терминал в корне проекта `A:\work\dev\product_cards_mvp` и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\product_tool\requirements.txt
.\.venv\Scripts\python.exe -m uvicorn product_tool.web:create_app --factory --host 127.0.0.1 --port 8000
```

Откройте **http://localhost:8000/**. Остановить сервер можно клавишами `Ctrl+C` в терминале.

1. Выберите файл `.xlsx` размером до 10 МБ.
2. Проверьте выбранный лист и предложенные номера колонок. При необходимости укажите их вручную и нажмите «Обновить предпросмотр».
3. В таблице поправьте бренд, основной артикул, запасную модель или категорию отдельной строки. Отметка «Нужно проверить» указывает на неполные или извлечённые из названия данные.
4. Нажмите «Подтвердить партию». На странице партии товары будут сгруппированы по категориям. Сохранённые партии доступны с главной страницы после перезапуска сервера.

Если в книге нет заголовков, укажите строку заголовков `0` и номера нужных колонок. Номера колонок начинаются с 1. Для подтверждения каждой строки нужны бренд и основной артикул; категория может остаться пустой и попадёт в группу «Категория не определена».

Загруженные книги находятся в `data/uploads/`, подтверждённые данные — в `data/batches.sqlite3`. Папка `data/`, файлы Excel и секреты исключены из Git. Чтобы хранить локальные данные в другом месте, задайте переменную окружения `PRODUCT_CARDS_DATA_DIR` до запуска сервера.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты сами создают временные книги Excel и базы данных. Им не нужны материалы из прежней папки или личные файлы.

## Состав проекта

- `product_tool/web.py` — локальная страница и маршрут подтверждения.
- `product_tool/storage.py` — сохранение черновиков и партий в SQLite.
- `product_tool/importer.py` — чтение Excel и распознавание товаров; его также можно запускать отдельно по инструкции в [product_tool/README.md](product_tool/README.md).
- `tests/` — проверки импортёра и веб-маршрута.
- `docs/` — архитектура MVP и рабочие сценарии.
