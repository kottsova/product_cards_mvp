# Product Cards MVP

Локальное FastAPI-приложение для загрузки Excel, проверки товаров LG по нескольким источникам и ручного подтверждения результата. Партии, источники, исходные факты, решения, документы и выбор фотографий хранятся в SQLite. Правила Sulpak и Mechta применяются только к LG.

## Установка и запуск в Windows PowerShell

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\product_tool\requirements.txt
```

Сайт, первый терминал:

```powershell
.\.venv\Scripts\python.exe -m uvicorn product_tool.web:create_app --factory --host 127.0.0.1 --port 8765
```

Worker, второй терминал:

```powershell
.\.venv\Scripts\python.exe -m product_tool.worker
```

Откройте **http://localhost:8765/**. Оба процесса используют `data/batches.sqlite3`. При использовании `PRODUCT_CARDS_DATA_DIR` задайте одинаковое значение в обоих терминалах.

## Этапы LG

1. **Источники и модель** — полный входной артикул, базовая модель, LG Казахстан, LG Россия, затем Sulpak и Mechta для полного артикула.
2. **Описание** — содержательные блоки каждой официальной страницы отдельно.
3. **Характеристики** — исходные факты каждого источника, нормализация и итог.
4. **Фотографии** — кандидаты товарной галереи, особенности и исключённые изображения; пользователь сохраняет выбор ссылок.
5. **Видео** — номер зарезервирован.
6. **Инструкции** — только русские официальные документы LG по доказанной на товарной странице связи с моделью поддержки.

Один HTTP-запрос ограничен 10 секундами и одной повторной попыткой. Официальные регионы делят бюджет около 20 секунд, fallback LG — 30 секунд, общий поиск источников товара — 60 секунд. Недоступный регион или поставщик сохраняется с ошибкой и не считается успехом.

## Статусы характеристик

- **Найдено только у базовой модели LG** (`official_base_only`) — значение есть только у официальной базовой модели, полного SKU оно не подтверждает и конфликтом не является.
- **Подтверждено одним поставщиком** — значение полного SKU подтвердил Sulpak или Mechta.
- **Подтверждено двумя поставщиками** — оба поставщика полного SKU совпали.
- **Различие официальных регионов** — LG Казахстан и LG Россия дали разные нормализованные значения.
- **Нужна проверка** — минимум два источника дали разные значения.
- **Выбрано вручную** — решение сотрудника; оно имеет приоритет после повторного запуска.

Страница задания отдельно показывает число реальных конфликтов, характеристик только от базовой модели и значений, подтверждённых поставщиком полного артикула. В интерфейсе и Excel используются русские названия и значения: `Да/Нет`, `кг`, `мм`, `об/мин`, размеры в порядке `Ш × В × Г`.

## Инструкции

Worker сначала извлекает официальную ссылку поддержки из HTML товарной страницы LG Россия. Для `S3WER` допустима связанная модель `S3RERB`, потому что связь опубликована самим LG. Сохраняются только русские документы, их дата, размер, модель поддержки и прямая ссылка `gscs-b2c.lge.com`. PDF не скачивается. Повторный запуск этапа 6 заменяет список без дублей.

## Фотографии

Официальная товарная галерея выбирается по умолчанию. Инфографика остаётся отдельной группой. Фото поставщиков по умолчанию не выбираются. Sulpak фильтрует баннеры, логотипы и служебные изображения; варианты `_160` и `_320` объединяются с оригиналом. Ручной выбор сохраняется по `asset_key` после повторного этапа 4. Изображения не скачиваются и не обрабатываются.

## Excel export

На странице партии доступна выгрузка с:

- листами категорий с итоговыми русскими значениями;
- листом «Проверка источников»;
- листом «Источники»;
- листом «Инструкции»;
- листом «Фотографии» только с выбранными ссылками.

## Данные и безопасность

`data/`, загруженные Excel, SQLite, сохранённые HTML, изображения, PDF, выгрузки, `.env`, `credentials.json` и ключи исключены из Git. Приложение не использует старый парсер, Google Sheets или фиксированные пути к диску `A:`.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m py_compile product_tool\*.py product_tool\adapters\*.py
```

Тесты используют встроенные HTML fixtures и временные SQLite/Excel без интернета. Живая проверка выполняется отдельно, поскольку сайты могут менять HTML или блокировать запросы.
