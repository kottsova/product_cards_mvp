# Рабочие сценарии и развитие MVP

## Что общее для команды

Сотрудник получает названия и коды товаров в Excel, находит точную модель и её вариант, собирает материалы для карточки, проверяет недостающие поля и выгружает результат. Подтверждённые человеком значения и исходный файл сохраняются. Результат поиска сопровождается ссылкой на источник и состоянием проверки. Категории и требуемые поля добавляются постепенно без переделки загрузки и очереди.

Первый пилот использует три исходных товара LG и пять добавленных названий Samsung, Lenovo и Apple. Список категорий пилота не ограничивает будущие категории.

## Чем отличается процесс Кати

| Область | Наблюдение | Что учитывать в продукте |
| --- | --- | --- |
| Точность модели | Региональный суффикс артикула, диагональ ТВ, комплект фотоаппарата с объективом или без него могут менять свойства товара. | Хранить полный код и вариант. Не подставлять данные близкой модели без проверки. |
| Фото | У разных диагоналей и локализаций ТВ может отличаться внешний вид, включая ножку. Сейчас фото скачиваются расширением и обрабатываются пакетным скриптом Photoshop. | Проверять соответствие фото точному товару. Сохранить отдельные исходные и обработанные фото; интеграцию с готовым скриптом рассмотреть после базового поиска. |
| Источники | Основной поиск ручной; ChatGPT помогает с трудными моделями. Для малоизвестных китайских товаров данные иногда ищутся на Ozon и сверяются по нескольким сайтам. | Указывать источник каждого значения. Источник магазина использовать как запасной и отправлять сомнительные совпадения на проверку. |
| Категории | Для стилусов важна совместимость; для ноутбуков и клавиатур — раскладка и форма Enter; для фотоаппаратов — комплектация. | Правила полноты и признаки варианта задавать по категории, а не по сотруднику или бренду. |
| Описания | Обычно берутся у дилеров; SEO-описание может потребоваться позднее. | Хранить найденный текст отдельно от будущего адаптированного описания. Автоматическую генерацию не включать в первый поиск. |
| Объём | Около 40 товаров в день. | Нужны пакетная загрузка, прогресс, быстрый фильтр «нужна проверка» и повторный запуск только нужных этапов. |

Заметка «для ТВ обязательное поле, если телетекст — функция ТВ, режим разработчика» пока неоднозначна. До уточнения она не превращается в правило проверки.

## Категории Кати для будущих итераций

Телевизоры; аудиотехника; чехлы; автомагнитолы; домашние кинотеатры; зеркальные фотоаппараты, экшн-камеры и камеры моментальной печати; сетевые фильтры; пауэрбанки; аксессуары для смартфонов, планшетов и ноутбуков; ноутбуки; планшеты; смартфоны; стабилизаторы для смартфонов; защитные стёкла; электронные книги; батарейки; микрофоны; комплектующие ПК; роутеры, ресиверы и IP-камеры; умный дом; фотобумага; геймпады.

Это перечень наблюдений, а не обещание, что каждая категория будет автоматически обработана в первой версии. Для каждой понадобятся примеры строк, поля проверки и источники.

## Данные, которые закладываем в основу сейчас

- **Исходная строка:** файл, лист, номер строки, все значения без изменений.
- **Идентичность товара:** бренд, полный артикул, модель, необязательный штрихкод, регион, цвет, комплектация и другие признаки варианта, если известны.
- **Категория:** исходное значение или предположение из названия, способ определения и подтверждение сотрудником.
- **Найденное значение:** само значение, ссылка на источник, этап поиска и состояние проверки.
- **Материалы:** фотографии, видео, инструкции и их источники. Корректность материалов проверяется по точному варианту товара.
- **Проблемы:** не найдено, неоднозначная модель, конфликт источников, не хватает обязательного поля, источник недоступен, этап не поддерживается.

## Начало сборки

1. **Импорт и предпросмотр.** Принимать разные Excel, позволять указать номера колонок; извлекать бренд, код и категорию из названия там, где отдельных колонок нет. Показывать сомнительные строки до запуска. Проверить на восьми тестовых товарах.
2. **Партия и категория.** Сохранить исходные строки, сгруппировать товары по категории, дать исправить группу и выгрузить книгу с отдельными листами. Статусы хранятся в базе приложения.
3. **Режимы поиска.** Единый запускатель принимает список этапов 1–6; адаптер LG использует проверенные функции нынешних режимов 6–9. Затем добавляются адаптеры других сайтов. Выбор только фото не запускает описание и характеристики.
4. **Проверка человеком.** Список проблемных товаров, источник каждого значения, подтверждение или исправление, повторный запуск отдельных этапов без потери подтверждённых данных.
5. **Доступ коллег.** Локально проверить весь маршрут, затем открыть ссылку с логином для удалённого пилота. Нынешний n8n остаётся работать; новый общий workflow подключается к запуску задания после появления устойчивой обработки партии.

После первого сквозного маршрута на LG можно по одному добавлять сценарии Кати: сначала телевизоры и ноутбуки как примеры строгой проверки варианта, затем категории с редкими источниками и совместимостью.

## Что потребуется уточнить по мере расширения

- Образцы входных строк и готовых карточек Кати по приоритетным категориям.
- Точный смысл условий для телетекста и режима разработчика ТВ.
- Какие магазинные источники допустимы и как отмечать расхождение официального сайта и дилера.
- Как выглядит выход готового Photoshop-скрипта и какой способ передачи фото нужен коллегам.
- Какие поля обязаны быть заполнены до ручного этапа в ChatGPT для каждой категории.
